# Security Policy

## Supported Versions

Security fixes are currently focused on the latest development version.
No formal long-term support schedule is currently provided.

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in public issues.

If GitHub Private Vulnerability Reporting is enabled for this repository,
use the repository Security tab to submit a private report.

A report should include:
- A description of the vulnerability.
- Reproduction steps or a proof of concept.
- Potential impact and affected version.
- Any suggested mitigation.

Please do not include real credentials, API keys, access tokens,
personal data, or private user logs in reports.

## Scope and Limitations

Guardian is a security monitoring application under development.
It must not be treated as a replacement for antivirus, EDR,
firewall, or other dedicated security controls.

AI-generated assessments are advisory and may be incorrect.
