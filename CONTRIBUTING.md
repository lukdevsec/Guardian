# Contributing to Guardian

Thank you for your interest in contributing.

## Before You Start

- Check existing issues before opening a new one.
- For security vulnerabilities, follow SECURITY.md instead of opening a public issue.
- Keep changes focused and explain their purpose.
- Do not include secrets, credentials, private logs, or personal data.

## Development

Guardian targets Windows and uses .NET 10 and Windows App SDK.

Before submitting a change:

1. Restore NuGet dependencies.
2. Build the relevant projects on a supported Windows development environment.
3. Test affected functionality.
4. Review the diff for accidental configuration changes or secrets.

## Pull Requests

Please include:

- A clear description of the change.
- The reason for the change.
- Relevant testing performed.
- Screenshots for user-interface changes, where useful.
